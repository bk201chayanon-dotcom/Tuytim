# Active Recall — ยาที่ใช้ในระบบทางเดินหายใจ

เว็บถามตอบแบบ **Active recall** สำหรับทบทวนเนื้อหา *Drugs used in Respiratory System*
ระบบจะถามก่อน ให้ผู้เรียนนึกและพิมพ์คำตอบเอง แล้วค่อยเปิดเฉลยเทียบทีละประเด็น
ทำงานทั้งหมดในเบราว์เซอร์ ไม่ต้องใช้เซิร์ฟเวอร์ ไม่ต้อง build

## ทำไมต้องพิมพ์คำตอบก่อน

หัวใจของ active recall คือ *การพยายามดึงความจำออกมาเอง* ไม่ใช่การอ่านซ้ำ
เว็บนี้จึงบังคับให้เขียนสิ่งที่นึกออกก่อนเปิดเฉลย (ปิดได้ในหน้าเริ่มทบทวน)
แล้วแสดง **ประเด็นที่ต้องได้** เป็นรายการให้ติ๊กเทียบทีละข้อ ก่อนให้คะแนนตัวเอง

## คุณสมบัติ

- **143 คำถาม ใน 20 หัวข้อ** ครอบคลุมทั้งเล่ม — พยาธิสรีรวิทยา Asthma/COPD,
  ยาขยายหลอดลม, corticosteroid, mediator antagonist, biologics, GINA/GOLD,
  allergic rhinitis, antihistamine, decongestant, antitussive, mucolytic และ PAH
- **คำถาม 3 ชนิด** — ปลายเปิด (เทียบประเด็นเอง), เติมคำ (ตรวจอัตโนมัติ)
  และปรนัย (ตรวจอัตโนมัติ พร้อมคำอธิบายว่าทำไมข้ออื่นถึงไม่ใช่)
- **จัดตารางทบทวนแบบกล่อง (Leitner)** — ตอบได้เลื่อนขึ้นกล่อง ระยะห่างยาวขึ้น
  1 → 3 → 7 → 16 → 35 → 90 วัน ตอบไม่ได้ตกกลับกล่องแรกและวนกลับมาถามซ้ำในรอบเดียวกัน
- **4 โหมดทบทวน** — ถึงกำหนด+ข้อใหม่, เฉพาะข้อที่เคยตอบไม่ได้, สุ่มทุกข้อ, เฉพาะข้อที่ยังไม่เคยเจอ
- **จำกัดข้อใหม่ต่อวัน** ปรับได้ในหน้าตั้งค่า (ค่าเริ่มต้น 15 ข้อ/วัน)
- **คลังคำถาม** ค้นหาข้อความล้วนและกรองตามหัวข้อ พร้อมดูเฉลยได้ทันที
- **สถิติ** — อัตราตอบได้เต็ม, ความคืบหน้ารายหัวข้อ, กราฟภาระทบทวน 14 วัน และประวัติ 10 วันล่าสุด
- **บันทึกอัตโนมัติ** ใน `localStorage` พร้อมส่งออก/นำเข้าเป็นไฟล์ JSON
- **ธีมมืด/สว่าง** ตามค่าของระบบ พร้อมปุ่มสลับที่ชนะค่าระบบ และรองรับหน้าจอมือถือ

## แป้นพิมพ์ลัด

| ปุ่ม | การทำงาน |
|---|---|
| `Ctrl` + `Enter` | ส่งคำตอบ · เปิดเฉลย |
| `1` `2` `3` | ให้คะแนนตัวเอง: ลืม · เกือบได้ · จำได้ |
| `1`–`4` | เลือกตัวเลือกในข้อปรนัย (ก่อนเปิดเฉลย) |
| `Esc` | ออกจากรอบทบทวน |

## การใช้งาน

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย หรือเสิร์ฟผ่านเว็บเซิร์ฟเวอร์ธรรมดา:

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000/resp-recall/
```

## โครงสร้างไฟล์

```
index.html                โครงหน้าเว็บและทุกหน้าจอ
assets/css/styles.css     สไตล์ทั้งหมด (ธีมสว่าง/มืดผ่าน CSS custom properties)
assets/js/questions.js    คลังคำถามทั้งหมด
assets/js/recall.js       ตัวจัดตารางทบทวนแบบกล่อง (ทดสอบแยกได้ด้วย Node)
assets/js/app.js          คิวคำถาม การแสดงผล และการบันทึกข้อมูล
```

## รวมเป็นไฟล์เดียว

สั่ง `node build.js` ที่รากของ repo จะได้ไฟล์ใน `dist/`

- `resp-recall.html` — ไฟล์เดียวจบ เปิดหรือส่งต่อให้ใช้แบบออฟไลน์ได้
- `resp-recall.embed.html` — ตัดแท็ก `<html>/<head>/<body>` ออก สำหรับโฮสต์ที่ห่อโครงเอกสารให้เอง

## การเพิ่มหรือแก้ไขคำถาม

แก้ที่ `assets/js/questions.js` เท่านั้น คำถามรองรับ 3 รูปแบบ:

```js
// ปลายเปิด — points คือประเด็นที่ต้องได้ ใช้ติ๊กเทียบตอนเปิดเฉลย
{ t:'qa', q:'คำถาม?', points:['ประเด็นที่ 1','ประเด็นที่ 2'], a:'<b>เฉลย</b>', src:'สไลด์ 28' }

// เติมคำ — accept คือคำตอบที่ยอมรับ (ตรวจแบบไม่สนตัวพิมพ์ ช่องว่าง และเครื่องหมาย)
{ t:'fill', q:'ตัวรับหลักที่ทำให้หลอดลมหดคือ ______', accept:['M3','M3 receptor'], a:'เฉลย', src:'สไลด์ 41' }

// ปรนัย — correct คือดัชนีของตัวเลือกที่ถูก เริ่มนับที่ 0
{ t:'mcq', q:'คำถาม?', choices:['ก','ข','ค','ง'], correct:2, a:'คำอธิบาย', src:'สไลด์ 15' }
```

`id` ของคำถามสร้างจาก `<topicId>-<ลำดับในหัวข้อ>` การ**แทรก**คำถามกลางหัวข้อจะทำให้
ลำดับเลื่อน และความคืบหน้าเดิมของข้อหลังจุดนั้นเคลื่อนตามไปด้วย —
หากต้องการรักษาความคืบหน้าไว้ ให้เพิ่มคำถามใหม่ต่อท้ายหัวข้อ
