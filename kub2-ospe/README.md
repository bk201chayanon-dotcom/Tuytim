# KUB II Patho OSPE

เว็บฝึก OSPE pathology บล็อก KUB II จาก *Lab urinary system* (66 สไลด์) ร่วมกับข้อสอบเก่า
**LAB 499316 ปีการศึกษา 2563 (MED24 ST16)** และ **Lab KUB2 MED NU23 & NT15**

## เปิดใช้งาน

เปิด `index.html` ได้ทันที (ภาพโหลดจากโฟลเดอร์ `img/` ข้าง ๆ) หรือเสิร์ฟทั้งโฟลเดอร์:

```bash
python3 -m http.server 8000   # แล้วเปิด http://localhost:8000/kub2-ospe/
```

## ภาพ

- `img/Lxx*.jpg` — ภาพจาก Lecture หน้า xx (`L39ic` / `L39pi` / `L39gbm` = IF สามแบบในหน้า 39)
- `img/X63-*.jpg` — ภาพจากข้อสอบปี 2563, `img/N23-*.jpg` — ภาพจากข้อสอบ NU23
- ไฟล์ที่ลงท้าย `-a` คือภาพต้นฉบับที่มี label คำตอบ ใช้ตอนเปิดเฉลยเท่านั้น
  ตัวที่ใช้ตั้งคำถามถูกลบ label ด้วย inpainting แล้ว (ARPKD หน้า 10, DM หน้า 29, ฉลาก museum หน้า 20,
  ข้อสอบ 2563 ข้อ 7, virtual slide AML และ chronic pyelonephritis)
- ตะกอนปัสสาวะที่เอกสารไม่มีภาพ (triple phosphate, cystine, casts ฯลฯ) เป็น **ภาพวาดจำลอง SVG**
  จาก `src/urine.js` ทุกภาพติดป้าย "ภาพวาดจำลอง"

## แก้เนื้อหา

แก้ที่ `src/` แล้วรัน `node kub2-ospe/build.js` เพื่อสร้าง `index.html` (เอกสารเต็ม) และ
`embed.html` (ไม่มี `<html>/<head>/<body>` สำหรับโฮสต์ที่ห่อให้เอง) build จะตรวจว่าภาพที่อ้างถึงมีครบ

- `src/data.js` — หัวข้อ Atlas, สถานี, ข้อสอบเก่า (คีย์ตรวจ `k` เป็นกลุ่มคำพ้อง, `n` = จำนวนจุดที่ต้องได้)
- `src/urine.js` — ภาพวาดตะกอนปัสสาวะ
- `src/app.js` — การทำงานทุกหน้า · `src/style.css` — สไตล์ · `src/shell.html` — โครงหน้า

ความคืบหน้าและประวัติสอบเก็บใน `localStorage` ของเบราว์เซอร์ที่ใช้เท่านั้น

> หมายเหตุเนื้อหา: หน้า 17 ของ Lecture ไม่มีชื่อสไลด์ จัดเป็น histology ของ renal infarction
> (coagulative necrosis) ตามลำดับสไลด์ · ตัวเลขขั้นตอน urinalysis นอกเหนือจากที่ข้อสอบถาม
> (เวลาปั่น 5 นาที, ตะกอน 0.5–1 mL) เป็นวิธีมาตรฐานทั่วไป ไม่ได้มาจากเอกสารที่แนบ
