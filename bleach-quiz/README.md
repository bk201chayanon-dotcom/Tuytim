# BLEACH เทพมรณะ — เกมทายคำวางบนหน้าผาก

เกมถามตอบแบบแฟนพันธุ์แท้เรื่อง **BLEACH เทพมรณะ** สำหรับเล่นกันเป็นกลุ่ม
คนตอบวางโทรศัพท์ไว้บนหน้าผากโดยหันจอออกให้เพื่อน ๆ เห็น เพื่อนช่วยกันใบ้
ตอบให้ได้มากที่สุดภายในเวลาที่กำหนด ทำงานทั้งหมดในเบราว์เซอร์ ไม่ต้องต่อเน็ต

## กติกา

1. คนตอบวางโทรศัพท์ไว้บนหน้าผาก หันจอออกให้เพื่อน ๆ เห็น ตัวเองห้ามชะโงกดู
2. เพื่อนที่เห็นจอช่วยกันใบ้เอง จอไม่บอกอะไรนอกจากคำตอบ
   ห้ามพูดคำที่อยู่บนจอหรือคำแปลตรง ๆ
3. ตอบถูก เพื่อนกดปุ่ม **ถูกต้อง** · ใบ้ไม่ออกหรือคิดไม่ทัน กดปุ่ม **ข้าม**
4. เล่นรัวไปเรื่อย ๆ จนหมดเวลา **100 วินาที** จำนวนข้อที่ตอบถูกคือคะแนน

## คุณสมบัติ

- **คำถาม 165 ข้อ ใน 4 หมวด** — ชินิงามิ & พวกพ้อง (45), ซันปักโต & ท่าไม้ตาย (40),
  อารันคาร์ & ควินซี่ (40), ศัพท์ & สถานที่ (40) หรือจะสุ่มรวมทุกหมวดก็ได้
- **จับเวลา 100 วินาที** เลือกเป็น 60 หรือ 150 วินาทีก็ได้ พร้อมแถบเรอิอัตสึที่ค่อย ๆ หด
  และเสียงติ๊กเตือนช่วง 10 วินาทีสุดท้าย
- **สองปุ่มใหญ่เต็มความกว้างจอ** แบ่งด้วยรอยเฉียง กดพลาดยาก แม้ถือจ่อหน้าผาก
- **ไม่มีคำใบ้บนจอ** โดยตั้งใจ — จอโชว์แค่คำตอบ เพื่อนที่ใบ้ต้องใช้ความรู้ตัวเอง
- **ปรับขนาดตัวอักษรอัตโนมัติ** ชื่อทับศัพท์ยาว ๆ จะย่อลงให้พอดีจอ และไม่ถูกตัดกลางคำ
- **สรุปผลท้ายเกม** บอกคะแนน ระดับ (จากชั้นรูคงไกถึงหน่วยศูนย์) และรายการข้อที่ผ่านไป
- **ไม่สุ่มซ้ำ ทั้งในรอบเดียวและข้ามรอบ** — คำที่เคยขึ้นจอแล้ว ไม่ว่าจะตอบถูก
  หรือกดข้าม จะไม่กลับมาอีกจนกว่าจะเจอครบทุกคำในหมวดนั้น หน้าปกบอกว่าเหลือคำใหม่
  กี่ข้อ และกด "ล้างประวัติ" เพื่อเริ่มนับใหม่ได้ทุกเมื่อ
- **จำสถิติสูงสุด** แยกตามหมวดและช่วงเวลาไว้ใน `localStorage`
- **กันจอดับระหว่างเล่น** ด้วย Wake Lock API พร้อมเสียงและการสั่นตอบรับทุกครั้งที่กด
- **คีย์ลัด** — ลูกศรขวา / เว้นวรรค คือตอบถูก, ลูกศรซ้าย คือข้าม, `Esc` คือจบเกม

## การใช้งาน

เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย หรือเสิร์ฟผ่านเว็บเซิร์ฟเวอร์ธรรมดา:

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000/bleach-quiz/
```

เล่นบนมือถือจะได้อารมณ์ที่สุด แนะนำให้**หมุนจอเป็นแนวนอน**และเปิดโหมดเต็มจอ

## รวมเป็นไฟล์เดียว

```bash
node bleach-quiz/build.js
```

จะได้ `bleach-quiz/dist/bleach-quiz.html` ที่ฝัง CSS และ JS ไว้ในไฟล์เดียว
เปิดออฟไลน์หรือส่งต่อให้เพื่อนได้ทันที และ `bleach-quiz.embed.html` สำหรับโฮสต์
ที่ห่อ `<html>` / `<head>` / `<body>` ให้เองอยู่แล้ว

## โครงสร้างไฟล์

```
bleach-quiz/
  index.html                 โครงหน้าและทั้งสี่ฉากของเกม
  assets/css/styles.css      ธีมมืดแบบชินิงามิ ทาสีทุกค่าไว้ชัดเจน
  assets/js/questions.js     คลังคำถามทั้งหมด — แก้เนื้อหาที่ไฟล์นี้ไฟล์เดียว
  assets/js/game.js          วงจรของเกม จับเวลา คะแนน เสียง และการเก็บค่า
  build.js                   รวมทุกอย่างเป็นไฟล์เดียวใน dist/
```

## การเพิ่มหรือแก้ไขคำถาม

แก้ที่ `assets/js/questions.js` เท่านั้น แต่ละข้อคือข้อความคำตอบล้วน ๆ

```js
{
  id: 'chars',
  name: 'ชินิงามิ & พวกพ้อง',
  kanji: '神',                       // ลายน้ำบนไพ่เลือกหมวด ใช้ตัวเดียว
  blurb: 'อิจิโกะ รูเกีย โกเทย์ 13 และคนรอบตัว',
  items: [
    'คุโรซากิ อิจิโกะ',
    'คุจิกิ รูเกีย'
  ]
}
```

คำตอบที่ยาวเกินหนึ่งบรรทัดไม่ต้องกังวล ตัวเกมจะย่อขนาดให้เอง —
แต่ควรเว้นวรรคระหว่างคำตามปกติ เพราะเกมใช้ช่องว่างเป็นจุดขึ้นบรรทัดใหม่

## หมายเหตุ

BLEACH เป็นผลงานของคุโบะ ไทเตะ · เกมนี้ทำขึ้นโดยแฟน ๆ เพื่อความบันเทิงเท่านั้น
ไม่มีความเกี่ยวข้องกับผู้ถือลิขสิทธิ์
