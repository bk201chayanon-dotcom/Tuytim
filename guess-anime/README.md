# ทายชื่ออนิเมะ — เกมทายชื่ออนิเมะจากคำใบ้

เกมทายชื่ออนิเมะที่เปิดคำใบ้ให้ทีละข้อ ยิ่งใช้คำใบ้น้อยยิ่งได้คะแนนมาก
ทำงานได้ทั้งหมดในเบราว์เซอร์ ไม่ต้องใช้เซิร์ฟเวอร์ ไม่ต้อง build

## คุณสมบัติ

- **อนิเมะ 80 เรื่อง** แบ่งเป็น 3 ระดับความยาก (ดังระดับโลก / รู้จักทั่วไป / สายลึก)
  หรือเลือกคละทั้งหมดก็ได้
- **คำใบ้ 4 ข้อต่อเรื่อง** เรียงจากกว้าง → เจาะจง เปิดเพิ่มได้ทีละข้อ (หักคะแนนทุกครั้งที่ขอ)
- **ตอบได้ 2 แบบ** พิมพ์ชื่อเอง หรือเลือกจาก 4 ตัวเลือก
- **ไม่สุ่มชื่อซ้ำ** — เรื่องที่เคยถูกถามไปแล้วจะถูกกันออกจากการสุ่มรอบถัดไปโดยอัตโนมัติ
  แม้จะเป็นผู้เล่นคนใหม่มาเล่นต่อบนเครื่องเดียวกันก็ตาม (ล้างประวัติได้จากหน้าแรก)
- **กระดานคะแนน** เก็บผลทุกคนที่ผลัดกันเล่น เรียงตามคะแนนเฉลี่ยต่อข้อ
- **หน้าคลังเรื่อง** ดูได้ว่าเรื่องไหนออกไปแล้ว/ยังไม่ออก พร้อมค้นหา
- **ธีมมืด/สว่าง** ตามค่าของระบบ พร้อมปุ่มสลับที่ชนะค่าระบบ และรองรับหน้าจอมือถือ

## แป้นพิมพ์ลัด

| ปุ่ม | การทำงาน |
|---|---|
| `Enter` | ส่งคำตอบ (โหมดพิมพ์) · ไปข้อถัดไปหลังเฉลยแล้ว |
| `H` | ขอคำใบ้เพิ่ม |
| `S` | ยอมแพ้ข้อนี้ |

## การใช้งาน

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย หรือเสิร์ฟผ่านเว็บเซิร์ฟเวอร์ธรรมดา:

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

## โครงสร้างไฟล์

```
index.html             โครงหน้าเว็บและทุกหน้าจอ
assets/css/styles.css  สไตล์ทั้งหมด (ธีมสว่าง/มืดผ่าน CSS custom properties)
assets/js/data.js      คลังอนิเมะและคำใบ้ทั้งหมด
assets/js/game.js      ตรรกะเกม: พูลไม่ให้ซ้ำ, คะแนน, ตรวจคำตอบ, กระดานคะแนน
assets/js/app.js       การเชื่อม UI: สลับหน้า, เล่นเกม, เรนเดอร์ผล
```

## การเพิ่มหรือแก้ไขเรื่องในคลัง

แก้ที่ `assets/js/data.js` เท่านั้น แต่ละเรื่องมีโครงสร้าง:

```js
{ id:'ตัวระบุไม่ซ้ำ', title:'ชื่อที่แสดงเป็นคำตอบ', tier:1, genre:'แนว',
  aliases:['คำตอบที่ยอมรับทั้งหมด'],
  clues:['คำใบ้ 1 กว้างสุด', 'คำใบ้ 2', 'คำใบ้ 3', 'คำใบ้ 4 เจาะจงสุด'] }
```

`tier`: 1 = ดังระดับโลก, 2 = รู้จักทั่วไป, 3 = สายลึก/คัลท์

ข้อมูลความคืบหน้า (เรื่องที่ออกไปแล้ว + กระดานคะแนน) เก็บไว้ใน `localStorage`
ของเบราว์เซอร์เครื่องนั้น ๆ เท่านั้น ไม่มีการส่งออกไปที่ไหน
