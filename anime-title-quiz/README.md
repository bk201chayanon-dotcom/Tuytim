# เรื่องนี้เรื่องอะไร — เกมใบ้ชื่อเรื่องอนิเมะวางบนหน้าผาก

เกมใบ้ชื่อสำหรับเล่นกันเป็นกลุ่ม ใช้กติกาเดียวกับ [`anime-quiz/`](../anime-quiz/)
แต่เปลี่ยนจากชื่อตัวละครเป็น **ชื่อเรื่องอนิเมะ** 232 เรื่อง
คนตอบวางโทรศัพท์บนหน้าผากโดยหันจอออกให้เพื่อน เพื่อนช่วยกันใบ้
ทายให้ได้มากที่สุดภายในเวลาที่กำหนด ทำงานทั้งหมดในเบราว์เซอร์ ไม่ต้องต่อเน็ต

## กติกา

1. คนตอบวางโทรศัพท์ไว้บนหน้าผาก หันจอออกให้เพื่อน ๆ เห็น ตัวเองห้ามชะโงกดู
2. เพื่อนที่เห็นจอช่วยกันใบ้เอง จอไม่บอกอะไรนอกจากชื่อเรื่อง
   ห้ามพูดชื่อบนจอหรือส่วนหนึ่งของชื่อ
3. ตอบถูก เพื่อนกดปุ่ม **ถูกต้อง** · ใบ้ไม่ออกหรือคิดไม่ทัน กดปุ่ม **ข้าม**
4. เล่นรัวไปเรื่อย ๆ จนหมดเวลา **100 วินาที** จำนวนเรื่องที่ตอบถูกคือคะแนน

## หมวดคำถาม

| หมวด | จำนวน | เนื้อหา |
|---|---|---|
| คลาสสิกในตำนาน | 67 | ยุคจอตู้ ยุควิดีโอ ยุคการ์ตูนเช้าวันเสาร์ |
| โชเน็นสายบู๊ | 49 | สายต่อสู้ตั้งแต่ยุคจัมป์ถึงปัจจุบัน |
| ยุคใหม่มาแรง | 38 | เรื่องที่เพิ่งฮิตในสตรีมมิ่งไม่กี่ปีมานี้ |
| อนิเมะฉายโรง | 41 | จิบลิ ชินไก และหนังใหญ่ที่เข้าโรงบ้านเรา |
| กีฬา รัก สยอง | 37 | สายกีฬา สายรัก สายสยอง และสายชิลล์ |
| **รวมทุกหมวด** | **232** | สุ่มปนกันทั้งห้าหมวด |

ทุกชื่อใช้แบบที่คนไทยเรียกกันจริง ๆ ทั้งชื่อไทย ชื่อทับศัพท์ และชื่ออังกฤษ

## คุณสมบัติ

- **แต่ละหมวดมีสีประจำตัว** ใช้กับแท็บชื่อหมวดและแถบเวลา ในโหมดสุ่มปนกัน
  สีจะเปลี่ยนตามหมวดของเรื่องที่โผล่ขึ้นมา
- **จับเวลา 100 วินาที** เลือกเป็น 60 หรือ 150 วินาทีก็ได้ พร้อมเสียงติ๊กเตือน
  ช่วง 10 วินาทีสุดท้าย
- **สองปุ่มใหญ่คั่นด้วยร่องเฉียง** แบบช่องมังงะ กดพลาดยากแม้ถือจ่อหน้าผาก
  ปุ่มคงสีหมึกกับกระดาษไว้เสมอ ไม่เปลี่ยนตามหมวด
- **ไม่มีคำใบ้บนจอ** โดยตั้งใจ — เพื่อนที่ใบ้ต้องใช้ความรู้ตัวเอง
- **ไม่สุ่มซ้ำข้ามรอบ** เรื่องที่เคยขึ้นจอแล้ว (ทั้งตอบถูกและกดข้าม) จะไม่ถูกสุ่มมาอีก
  จนกว่าจะเจอครบทุกเรื่องในหมวดนั้น เล่นรอบใหม่จึงได้เรื่องใหม่เสมอ
- **ปรับขนาดตัวอักษรอัตโนมัติ** ชื่อยาว ๆ อย่าง "อาริเอตี้ มหัศจรรย์ความลับคนตัวจิ๋ว"
  จะย่อลงให้พอดีจอทั้งด้านสูงและด้านกว้าง และไม่ถูกตัดกลางคำ
- **สรุปผลท้ายเกม** บอกคะแนน ระดับ และรายการเรื่องที่ผ่านไปพร้อมป้ายบอกหมวด
- **จำสถิติสูงสุดแยกตามหมวดและความยาวเวลา** เก็บใน `localStorage` ของเครื่องนั้น

## การใช้งาน

เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย หรือส่งไฟล์เดียวจบใน `dist/` ให้เพื่อน:

```bash
node build.js          # รวมทุกอย่างเป็นไฟล์เดียว
```

- `dist/anime-title-quiz.html` — เปิดด้วยเบราว์เซอร์ได้ทันที ส่งต่อได้เลย
- `dist/anime-title-quiz.embed.html` — สำหรับโฮสต์ที่ห่อ `<html>/<head>/<body>` ให้เองแล้ว

## โครงสร้างไฟล์

```
index.html               โครงหน้าเว็บ ทั้ง 4 ฉาก (หน้าปก · เตรียมตัว · เล่น · สรุปผล)
assets/css/styles.css    ธีมหน้ากระดาษมังงะ และสีประจำหมวด
assets/js/questions.js   คลังชื่อเรื่อง 232 เรื่อง แบ่งเป็น 5 หมวด
assets/js/game.js        วงจรของเกม สุ่มไม่ซ้ำ จับเวลา เสียง และหน้าสรุปผล
build.js                 รวมทุกไฟล์เป็น HTML ไฟล์เดียวใน dist/
```

## เพิ่มเรื่องเอง

แก้ `assets/js/questions.js` เติมชื่อเรื่องลงใน `items` ของหมวดที่ต้องการ
แล้วรัน `node build.js` ใหม่ ระบบสุ่มไม่ซ้ำอ้างอิงจากตัวชื่อ ไม่ใช่ลำดับ
จึงสลับลำดับหรือแทรกกลางรายการได้โดยประวัติของผู้เล่นไม่เพี้ยน
