# neafy shop — เว็บขายเสื้อสไตล์คลาสสิก

เว็บไซต์ร้านขายเสื้อ **neafy shop** สำหรับสินค้า 2 แบบ ทำงานทั้งหมดในเบราว์เซอร์
ไม่ต้องใช้เซิร์ฟเวอร์ ไม่ต้อง build และไม่มี dependency ภายนอกนอกจากฟอนต์ Google Fonts

## คุณสมบัติ

- **หน้าร้านหน้าเดียว** — ฮีโร่, สินค้า, ตารางไซซ์, เรื่องของร้าน, คำถามที่พบบ่อย, ติดต่อ
- **หน้ารายละเอียดสินค้า** เปิดผ่าน `#product/<id>` (แชร์ลิงก์ตรงถึงสินค้าได้)
- **เลือกไซซ์พร้อมสต็อกจริง** ไซซ์ที่หมดถูกขีดทับและกดไม่ได้ พร้อมข้อความเตือนเมื่อเหลือน้อยกว่า 3 ตัว
- **ตะกร้าสินค้า** เพิ่ม/ลด/ลบ จำนวนไม่เกินสต็อก และจำค่าไว้ใน `localStorage` เมื่อปิดหน้าไปแล้วกลับมา
- **คิดค่าส่งอัตโนมัติ** พร้อมบอกว่าต้องซื้อเพิ่มอีกเท่าไรถึงจะส่งฟรี
- **ฟอร์มสั่งซื้อ** ตรวจชื่อ/เบอร์/ที่อยู่/รหัสไปรษณีย์ แล้วสรุปออเดอร์เป็นข้อความให้กดคัดลอกส่งไลน์
  (ไม่มีเซิร์ฟเวอร์รับออเดอร์ จึงไม่มีข้อมูลลูกค้าถูกส่งออกจากเครื่องผู้ใช้)
- **รองรับมือถือ** มีเมนูแฮมเบอร์เกอร์ และไม่มีการเลื่อนแนวนอน

## การใช้งาน

เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย หรือเสิร์ฟผ่านเว็บเซิร์ฟเวอร์ธรรมดา:

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000/neafy-shop/
```

## แก้ข้อมูลร้านและสินค้า

แก้ที่ **`assets/js/products.js`** ไฟล์เดียว ไม่ต้องแตะ HTML/CSS

| ต้องการแก้ | แก้ที่ |
|---|---|
| ชื่อเสื้อ / ราคา / รายละเอียด | `PRODUCTS[].name`, `.nameTh`, `.price`, `.description`, `.details` |
| รูปสินค้า | วางไฟล์ใน `images/` แล้วใส่ชื่อไฟล์ใน `PRODUCTS[].images` |
| ไซซ์และสต็อก | `PRODUCTS[].sizes` — `chest` `length` `shoulder` เป็นนิ้ว, `stock` คือจำนวนคงเหลือ |
| ป้ายมุมรูป | `PRODUCTS[].badge` (ใส่ `null` ถ้าไม่ต้องการ) |
| ราคาก่อนลด | `PRODUCTS[].compareAt` (ใส่ `null` ถ้าไม่มีโปร) |
| ไลน์ / เบอร์ / อีเมล / ไอจี | `SHOP.contact` |
| ค่าส่งและยอดส่งฟรี | `SHOP.shippingFee`, `SHOP.freeShippingFrom` |

**เปลี่ยนรูปสินค้า:** วางไฟล์ลง `images/` แล้วแก้บรรทัด `images: [...]` ใน `products.js`
รูปแนะนำ **อัตราส่วนจัตุรัส 1:1** (เช่น 1254×1254 px) เพราะกรอบรูปทุกจุดใช้อัตราส่วนนี้
ควรบันทึกเป็น JPEG คุณภาพ ~88 เพื่อให้ไฟล์ไม่เกิน ~300 KB โหลดเร็วบนมือถือ

## รวมเป็นไฟล์เดียว

```bash
node neafy-shop/build.js
```

ได้ `dist/neafy-shop.html` — ไฟล์ HTML ไฟล์เดียวที่ฝัง CSS, JS และรูปสินค้าไว้ครบ
ดับเบิลคลิกเปิดได้ทันที ส่งต่อทางไลน์หรืออัปโหลดขึ้นโฮสต์ไหนก็ได้โดยไม่ต้องพกโฟลเดอร์
และ `dist/neafy-shop.embed.html` สำหรับโฮสต์ที่ห่อ `<html>/<head>/<body>` ให้เองอยู่แล้ว

## โครงสร้างไฟล์

```
index.html               โครงหน้าเว็บทั้งหมด
assets/css/shop.css      สไตล์ทั้งหมด (ตัวแปรสีอยู่บนสุดของไฟล์)
assets/js/products.js    ข้อมูลสินค้าและการตั้งค่าร้าน — แก้ไฟล์นี้เป็นหลัก
assets/js/shop.js        ตรรกะ: แสดงสินค้า, เลือกไซซ์, ตะกร้า, ฟอร์มสั่งซื้อ
images/                  รูปสินค้า (tee-wolf.jpg, tee-gun-nef.jpg)
build.js                 รวมทุกอย่างเป็นไฟล์ HTML ไฟล์เดียวใน dist/
```

## หมายเหตุ

ระบบสั่งซื้อจบที่การสรุปข้อความให้ลูกค้าคัดลอกไปส่งทางไลน์ ยังไม่ได้ต่อกับระบบชำระเงินจริง
ถ้าต้องการรับชำระเงินอัตโนมัติ (พร้อมเพย์ QR, บัตรเครดิต) ต้องมีฝั่งเซิร์ฟเวอร์เพิ่ม
