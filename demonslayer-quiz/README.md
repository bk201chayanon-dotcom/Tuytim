# ดาบพิฆาตอสูร ทายคำ — เกมใบ้คำวางบนหน้าผาก

เกมใบ้คำสำหรับเล่นกันเป็นกลุ่ม ใช้กติกาเดียวกับ [`anime-quiz/`](../anime-quiz/)
และ [`football-quiz/`](../football-quiz/) แต่เนื้อหาเป็นชื่อตัวละครและศัพท์เฉพาะ
จากอนิเมะ **ดาบพิฆาตอสูร (Demon Slayer / Kimetsu no Yaiba)** รวม 161 คำ
คนตอบวางโทรศัพท์บนหน้าผากโดยหันจอออกให้เพื่อน เพื่อนช่วยกันใบ้
ทายให้ได้มากที่สุดภายในเวลาที่กำหนด ทำงานทั้งหมดในเบราว์เซอร์ ไม่ต้องต่อเน็ต

## กติกา

1. คนตอบวางโทรศัพท์ไว้บนหน้าผาก หันจอออกให้เพื่อน ๆ เห็น ตัวเองห้ามชะโงกดู
2. เพื่อนที่เห็นจอช่วยกันใบ้เอง จอไม่บอกอะไรนอกจากคำ
   ห้ามพูดคำบนจอหรือส่วนหนึ่งของคำ
3. ตอบถูก เพื่อนกดปุ่ม **ถูกต้อง** · ใบ้ไม่ออกหรือคิดไม่ทัน กดปุ่ม **ข้าม**
4. เล่นรัวไปเรื่อย ๆ จนหมดเวลา **100 วินาที** จำนวนคำที่ตอบถูกคือคะแนน
5. เปลี่ยนคนทายแล้วเล่นต่อได้เลย คำที่เคยขึ้นจอไปแล้วจะไม่กลับมาอีก

## หมวด

| หมวด | จำนวน | เนื้อหา |
|---|---|---|
| นักดาบพิฆาตอสูร | 59 | ทันจิโร่ เสาหลักทั้งเก้า ตระกูลอุบุยาชิกิ และคนของหน่วยพิฆาตอสูร |
| อสูร | 37 | มุซัน สิบสองคิซึกิ และอสูรที่เคยขวางทางในเรื่อง |
| ลมหายใจ & ศัพท์เฉพาะ | 65 | ลมหายใจทั้งสิบสี่ ศัพท์เฉพาะ อาวุธ และสถานที่สำคัญ |
| รวมทุกหมวด | 161 | สุ่มปนกันทั้งสามหมวด |

## คุณสมบัติ

- **ไม่สุ่มซ้ำ ทั้งในรอบเดียวและข้ามรอบ** — เปลี่ยนคนทายแล้วเล่นรอบใหม่
  จะได้คำใหม่ทั้งหมด คำที่เคยขึ้นจอแล้ว ไม่ว่าจะตอบถูกหรือกดข้าม
  จะไม่กลับมาอีกจนกว่าจะเจอครบทุกคำในหมวดนั้น หน้าปกบอกว่าเหลือคำใหม่กี่คำ
  และกด "ล้างประวัติ" เพื่อเริ่มนับใหม่ได้ทุกเมื่อ
- **แต่ละหมวดมีสีประจำตัว** — นักดาบพิฆาตอสูรสีเขียวฮาโอริทันจิโร่
  อสูรสีแดงอมม่วง ลมหายใจ & ศัพท์เฉพาะสีม่วงดอกฟูจิ ใช้กับแท็บชื่อหมวดและแถบเวลา
  ในโหมดรวมทุกหมวด สีจะเปลี่ยนตามหมวดของคำที่โผล่ขึ้นมา
- **จับเวลา 100 วินาที** เลือกเป็น 60 หรือ 150 วินาทีก็ได้ พร้อมเสียงติ๊กเตือน
  ช่วง 10 วินาทีสุดท้าย
- **สองปุ่มใหญ่เต็มความกว้าง** ปุ่มคงสีครามกับแดงไว้เสมอ ไม่เปลี่ยนตามหมวด
  จะได้ไม่สับสนแม้ถือจ่อหน้าผาก
- **ไม่มีคำใบ้บนจอ** โดยตั้งใจ — เพื่อนที่ใบ้ต้องใช้ความรู้ตัวเอง
- **ปรับขนาดตัวอักษรอัตโนมัติ** คำยาว ๆ อย่าง "ช่างตีดาบสวมหน้ากากฮโยตโตโกะ"
  จะย่อลงให้พอดีจอ และไม่ถูกตัดกลางคำ
- **รอยฟันดาบนิจิริน** พาดกลางจอทุกครั้งที่ตอบถูก แทนแฟลชธรรมดา ๆ
- **สรุปผลท้ายเกม** บอกคะแนน ระดับ (จากนักดาบฝึกหัดถึงเทียบชั้นสึกิคุนิ โยริอิจิ)
  และรายการคำที่ผ่านไปพร้อมป้ายบอกว่ามาจากหมวดไหน
- **จำสถิติสูงสุด** แยกตามหมวดและช่วงเวลาไว้ใน `localStorage`
- **กันจอดับระหว่างเล่น** ด้วย Wake Lock API พร้อมเสียงและการสั่นตอบรับทุกครั้งที่กด
- **คีย์ลัด** — ลูกศรขวา / เว้นวรรค คือตอบถูก, ลูกศรซ้าย คือข้าม, `Esc` คือจบเกม

## หน้าตา

หน้าเว็บใช้ภาพจำของ **ราตรีล่าอสูรยุคไทโช** — พื้นครามเข้มอมม่วง
ลายตารางหมากรุกเขียว-ดำจากฮาโอริของทันจิโร่เป็นพื้นผิวจาง ๆ ทั่วทั้งหน้า
แสงจันทร์นวลจาง ๆ ที่มุมจอ และสีแดงเลือดของดาบนิจิรินเป็นสีเน้นเพียงสีเดียว
ตอนตอบถูกจะมีรอยฟันดาบพาดกลางจอแทนแฟลชธรรมดา
ตัวอักษรหัวเรื่องและคำถามใช้ Yuji Syuku (ฟอนต์พู่กันญี่ปุ่น) ผสม Noto Serif Thai
ส่วนเนื้อความใช้ Noto Sans Thai เป็นธีมมืดธีมเดียวโดยตั้งใจ
ทาสีไว้ครบทุกค่า จึงอ่านได้เหมือนกันทุกที่

## การใช้งาน

เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย หรือเสิร์ฟผ่านเว็บเซิร์ฟเวอร์ธรรมดา:

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000/demonslayer-quiz/
```

เล่นบนมือถือจะได้อารมณ์ที่สุด แนะนำให้**หมุนจอเป็นแนวนอน**และเปิดโหมดเต็มจอ

## รวมเป็นไฟล์เดียว

```bash
node demonslayer-quiz/build.js
```

จะได้ `demonslayer-quiz/dist/demonslayer-quiz.html` ที่ฝัง CSS และ JS ไว้ในไฟล์เดียว
เปิดออฟไลน์หรือส่งต่อให้เพื่อนได้ทันที และ `demonslayer-quiz.embed.html` สำหรับโฮสต์
ที่ห่อ `<html>` / `<head>` / `<body>` ให้เองอยู่แล้ว

## โครงสร้างไฟล์

```
demonslayer-quiz/
  index.html                 โครงหน้าและทั้งสี่ฉากของเกม
  assets/css/styles.css      ธีมราตรีล่าอสูรยุคไทโช ทาสีทุกค่าไว้ชัดเจน
  assets/js/questions.js     คลังคำถามทั้งหมด — แก้เนื้อหาที่ไฟล์นี้ไฟล์เดียว
  assets/js/game.js          วงจรของเกม จับเวลา คะแนน เสียง และการเก็บค่า
  build.js                   รวมทุกอย่างเป็นไฟล์เดียวใน dist/
```

เกมนี้แยกไฟล์ออกจากเกมอื่นในรีโปอย่างสมบูรณ์ ไม่แชร์โค้ดกัน
ตามแบบเดียวกับโปรเจกต์อื่นที่แต่ละอันเปิดเดี่ยว ๆ ได้เอง แก้อันหนึ่งจึงไม่กระทบอีกอัน

## การเพิ่มหรือแก้ไขคำถาม

แก้ที่ `assets/js/questions.js` เท่านั้น แต่ละข้อคือข้อความคำตอบล้วน ๆ

```js
{
  id: 'slayer',
  name: 'นักดาบพิฆาตอสูร',        // ชื่อบนแท็บระหว่างเล่น
  en: 'DEMON SLAYER CORPS',       // ชื่ออังกฤษบนไพ่เลือกหมวด
  hue: 'sl',                      // สีประจำหมวด ดูค่าที่ตั้งไว้ใน styles.css
  blurb: 'ทันจิโร่ เสาหลักทั้งเก้า และคนของหน่วยพิฆาตอสูร',
  items: [
    'คามาโดะ ทันจิโร่',
    'อากาสึมะ เซนอิทสึ'
  ]
}
```

คำที่ยาวเกินหนึ่งบรรทัดไม่ต้องกังวล ตัวเกมจะย่อขนาดให้เอง —
แต่ควรเว้นวรรคระหว่างคำตามปกติ เพราะเกมใช้ช่องว่างเป็นจุดขึ้นบรรทัดใหม่
และห้ามใส่คำซ้ำข้ามหมวด เพราะโหมดรวมทุกหมวดจะเจอคำเดียวกันสองครั้ง
