# ชื่อนี้ใครเอ่ย — เกมใบ้ชื่อตัวละครวางบนหน้าผาก

เกมใบ้ชื่อสำหรับเล่นกันเป็นกลุ่ม ใช้กติกาเดียวกับ [`bleach-quiz/`](../bleach-quiz/)
แต่เนื้อหาเป็น **ชื่อตัวละครล้วน ๆ** จากอนิเมะ 4 เรื่อง
คนตอบวางโทรศัพท์บนหน้าผากโดยหันจอออกให้เพื่อน เพื่อนช่วยกันใบ้
ทายให้ได้มากที่สุดภายในเวลาที่กำหนด ทำงานทั้งหมดในเบราว์เซอร์ ไม่ต้องต่อเน็ต

## กติกา

1. คนตอบวางโทรศัพท์ไว้บนหน้าผาก หันจอออกให้เพื่อน ๆ เห็น ตัวเองห้ามชะโงกดู
2. เพื่อนที่เห็นจอช่วยกันใบ้เอง จอไม่บอกอะไรนอกจากชื่อ
   ห้ามพูดชื่อบนจอหรือส่วนหนึ่งของชื่อ
3. ตอบถูก เพื่อนกดปุ่ม **ถูกต้อง** · ใบ้ไม่ออกหรือคิดไม่ทัน กดปุ่ม **ข้าม**
4. เล่นรัวไปเรื่อย ๆ จนหมดเวลา **100 วินาที** จำนวนชื่อที่ตอบถูกคือคะแนน

## คุณสมบัติ

- **ชื่อตัวละคร 202 ชื่อ จาก 4 เรื่อง** — วันพีช (52), ฮันเตอร์ x ฮันเตอร์ (47),
  นารูโตะ (55), โจโจ้ (48) เลือกเรื่องเดียวหรือสุ่มปนกันทั้งสี่เรื่องก็ได้
- **แต่ละเรื่องมีสีประจำตัว** ใช้กับแท็บชื่อเรื่องและแถบเวลา ในโหมดสุ่มปนกัน
  สีจะเปลี่ยนตามเรื่องของชื่อที่โผล่ขึ้นมา
- **จับเวลา 100 วินาที** เลือกเป็น 60 หรือ 150 วินาทีก็ได้ พร้อมเสียงติ๊กเตือน
  ช่วง 10 วินาทีสุดท้าย
- **สองปุ่มใหญ่คั่นด้วยร่องเฉียง** แบบช่องมังงะ กดพลาดยากแม้ถือจ่อหน้าผาก
  ปุ่มคงสีหมึกกับกระดาษไว้เสมอ ไม่เปลี่ยนตามเรื่อง จะได้ไม่สับสน
- **ไม่มีคำใบ้บนจอ** โดยตั้งใจ — เพื่อนที่ใบ้ต้องใช้ความรู้ตัวเอง
- **ปรับขนาดตัวอักษรอัตโนมัติ** ชื่อยาว ๆ อย่าง "โรเบิร์ต อี. โอ. สปีดวากอน"
  จะย่อลงให้พอดีจอ และไม่ถูกตัดกลางคำ
- **สรุปผลท้ายเกม** บอกคะแนน ระดับ และรายการชื่อที่ผ่านไปพร้อมป้ายบอกว่ามาจากเรื่องไหน
- **ไม่สุ่มซ้ำ ทั้งในรอบเดียวและข้ามรอบ** — ชื่อที่เคยขึ้นจอแล้ว ไม่ว่าจะตอบถูก
  หรือกดข้าม จะไม่กลับมาอีกจนกว่าจะเจอครบทุกชื่อในชุดนั้น หน้าปกบอกว่าเหลือชื่อใหม่
  กี่ชื่อ และกด "ล้างประวัติ" เพื่อเริ่มนับใหม่ได้ทุกเมื่อ
- **จำสถิติสูงสุด** แยกตามชุดและช่วงเวลาไว้ใน `localStorage`
- **กันจอดับระหว่างเล่น** ด้วย Wake Lock API พร้อมเสียงและการสั่นตอบรับทุกครั้งที่กด
- **คีย์ลัด** — ลูกศรขวา / เว้นวรรค คือตอบถูก, ลูกศรซ้าย คือข้าม, `Esc` คือจบเกม

## หน้าตา

หน้าเว็บใช้ภาพจำของ **หน้ากระดาษมังงะ** — กระดาษหนังสือพิมพ์อมเหลือง กรอบหมึกหนา
จุดสกรีนโทน และเส้นสปีดไลน์ที่พุ่งเข้ากลางจอทุกครั้งที่ตอบถูก
ตัวอักษรหัวเรื่องและชื่อตัวละครใช้ K2D ส่วนเนื้อความใช้ Sarabun
เป็นธีมสว่างธีมเดียวโดยตั้งใจ ทาสีไว้ครบทุกค่า จึงอ่านได้เหมือนกันทุกที่

## การใช้งาน

เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย หรือเสิร์ฟผ่านเว็บเซิร์ฟเวอร์ธรรมดา:

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000/anime-quiz/
```

เล่นบนมือถือจะได้อารมณ์ที่สุด แนะนำให้**หมุนจอเป็นแนวนอน**และเปิดโหมดเต็มจอ

## รวมเป็นไฟล์เดียว

```bash
node anime-quiz/build.js
```

จะได้ `anime-quiz/dist/anime-quiz.html` ที่ฝัง CSS และ JS ไว้ในไฟล์เดียว
เปิดออฟไลน์หรือส่งต่อให้เพื่อนได้ทันที และ `anime-quiz.embed.html` สำหรับโฮสต์
ที่ห่อ `<html>` / `<head>` / `<body>` ให้เองอยู่แล้ว

## โครงสร้างไฟล์

```
anime-quiz/
  index.html                 โครงหน้าและทั้งสี่ฉากของเกม
  assets/css/styles.css      ธีมหน้ากระดาษมังงะ ทาสีทุกค่าไว้ชัดเจน
  assets/js/questions.js     คลังชื่อตัวละคร — แก้เนื้อหาที่ไฟล์นี้ไฟล์เดียว
  assets/js/game.js          วงจรของเกม จับเวลา คะแนน เสียง และการเก็บค่า
  build.js                   รวมทุกอย่างเป็นไฟล์เดียวใน dist/
```

เกมนี้แยกไฟล์ออกจาก `bleach-quiz/` อย่างสมบูรณ์ ไม่แชร์โค้ดกัน
ตามแบบเดียวกับโปรเจกต์อื่นในรีโปนี้ที่แต่ละอันเปิดเดี่ยว ๆ ได้เอง
แก้อันหนึ่งจึงไม่กระทบอีกอัน

## การเพิ่มหรือแก้ไขชื่อ

แก้ที่ `assets/js/questions.js` เท่านั้น แต่ละข้อคือข้อความชื่อล้วน ๆ

```js
{
  id: 'onepiece',
  name: 'วันพีช',              // ชื่อบนแท็บระหว่างเล่น
  en: 'ONE PIECE',             // ชื่ออังกฤษบนไพ่เลือกเรื่อง
  hue: 'op',                   // สีประจำเรื่อง ดูค่าที่ตั้งไว้ใน styles.css
  blurb: 'กลุ่มหมวกฟาง ชิจิบุไค สี่จักรพรรดิ และกองทัพเรือ',
  items: [
    'มังกี้ ดี. ลูฟี่',
    'โรโรโนอา โซโล'
  ]
}
```

ชื่อที่ยาวเกินหนึ่งบรรทัดไม่ต้องกังวล ตัวเกมจะย่อขนาดให้เอง —
แต่ควรเว้นวรรคระหว่างคำตามปกติ เพราะเกมใช้ช่องว่างเป็นจุดขึ้นบรรทัดใหม่
และควรเลี่ยงชื่อที่ซ้ำกันข้ามเรื่อง (เช่น "ยามาโตะ" มีทั้งในวันพีชและนารูโตะ)
เพราะโหมดสุ่มปนกันจะเจอชื่อเดียวกันสองครั้ง

## หมายเหตุ

ตัวละครทั้งหมดเป็นของผู้แต่งและผู้ถือลิขสิทธิ์แต่ละเรื่อง ·
เกมนี้ทำขึ้นโดยแฟน ๆ เพื่อความบันเทิงเท่านั้น ไม่มีความเกี่ยวข้องกับผู้ถือลิขสิทธิ์
