# Anki CAD — แฟลชการ์ดทบทวน Coronary Artery Disease

เว็บไซต์แฟลชการ์ดแบบ [Anki](https://apps.ankiweb.net/) สำหรับทบทวนเนื้อหา
**Coronary artery disease** ด้วยระบบทบทวนแบบเว้นระยะ (spaced repetition)
ทำงานได้ทั้งหมดในเบราว์เซอร์ ไม่ต้องใช้เซิร์ฟเวอร์ ไม่ต้อง build

## คุณสมบัติ

- **65 การ์ด ใน 5 สำรับ** — พื้นฐาน & พยาธิกำเนิด, Chronic coronary syndrome,
  ACS & STEMI, NSTE-ACS / Unstable angina, ยา & Secondary prevention
- **อัลกอริทึม SM-2** แบบเดียวกับ Anki — มีขั้นเรียน (learning steps),
  ค่าความง่าย (ease factor), การลดระยะเมื่อตอบผิด (lapse) และการกระจายวันครบกำหนด (fuzz)
- **ปุ่มตอบ 4 ระดับ** ลืม / ยาก / ได้ / ง่าย พร้อมแสดงล่วงหน้าว่าจะเจอการ์ดนี้อีกเมื่อไร
- **จำกัดการ์ดใหม่ต่อวัน** ปรับได้ในหน้าตั้งค่า (ค่าเริ่มต้น 15 ใบ/วัน)
- **การ์ดเติมคำ (cloze)** นอกเหนือจากการ์ดถาม–ตอบปกติ
- **หน้าเรียกดูการ์ด** พร้อมค้นหาข้อความล้วนและกรองตามสำรับ
- **หน้าสถิติ** — อัตราตอบถูก, จำนวนการ์ดที่โตเต็มวัย และกราฟพยากรณ์ภาระทบทวน 14 วัน
- **บันทึกความคืบหน้าอัตโนมัติ** ใน `localStorage` พร้อมส่งออก/นำเข้าเป็นไฟล์ JSON
- **ธีมมืด/สว่าง** และรองรับหน้าจอมือถือ

## การใช้งาน

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย หรือเสิร์ฟผ่านเว็บเซิร์ฟเวอร์ธรรมดา:

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

## โครงสร้างไฟล์

```
index.html            โครงหน้าเว็บและทุกหน้าจอ
assets/css/styles.css สไตล์ทั้งหมด (ธีมมืด/สว่างผ่าน CSS variables)
assets/js/decks.js    เนื้อหาการ์ดทั้งหมด
assets/js/srs.js      อัลกอริทึมจัดตารางทบทวน SM-2 (ทดสอบแยกได้ด้วย Node)
assets/js/app.js      คิวทบทวน การแสดงผล และการบันทึกข้อมูล
```

## การเพิ่มหรือแก้ไขการ์ด

แก้ที่ `assets/js/decks.js` เท่านั้น การ์ดรองรับ 2 รูปแบบ:

```js
// การ์ดถาม–ตอบ (ช่อง q และ a รองรับ HTML)
{ q: 'คำถาม?', a: '<b>คำตอบ</b>', note: 'หมายเหตุเพิ่มเติม', src: 'slide 14' }

// การ์ดเติมคำ
{ cloze: 'ตีบ ≥ {{c1::50}}% ที่ left main', src: 'slide 16' }
```

`id` ของการ์ดสร้างจาก `<deckId>-<ลำดับในสำรับ>` การ**แทรก**การ์ดกลางสำรับจะทำให้
ลำดับเลื่อน และความคืบหน้าเดิมของการ์ดหลังจุดนั้นเคลื่อนตามไปด้วย —
หากต้องการรักษาความคืบหน้าไว้ ให้เพิ่มการ์ดใหม่ต่อท้ายสำรับ
