# OSPE Flashcards — CVS Pathology

เว็บ flashcard สำหรับติวสอบ OSPE (Objective Structured Practical Examination)
วิชาพยาธิวิทยา หมวดระบบหัวใจและหลอดเลือด (Cardiovascular System)
เป็นไฟล์ HTML ไฟล์เดียว เปิดออฟไลน์ได้ทันที ไม่ต้องติดตั้งอะไรเพิ่ม

ที่มาเนื้อหา: สไลด์ *LAB : CVS* โดย La-or Chompuk, M.D., Department of Pathology
(63 การ์ด ครอบคลุม atherosclerosis, arteriosclerosis, aortic disease,
myocardial infarction, cardiomyopathy, myocarditis, rheumatic heart disease,
infective endocarditis, โรคลิ้นหัวใจ, อุปกรณ์ฝังตัว, เนื้องอกหัวใจ/หลอดเลือด,
โรคเยื่อหุ้มหัวใจ และ vasculitis)

## วิธีใช้

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (Chrome/Edge/Firefox) ได้เลย ไม่ต้องเสิร์ฟผ่านเว็บเซิร์ฟเวอร์
ข้อมูลทั้งหมด (การ์ด รูปภาพ ความคืบหน้า) เก็บอยู่ใน **IndexedDB ของเบราว์เซอร์เครื่องนั้น**
เก็บสำรองด้วยการส่งออกเป็นไฟล์ JSON ในแท็บ "นำเข้า/ส่งออก" เป็นระยะ

## คุณสมบัติ

- **การ์ดแต่ละใบ**: รูปภาพ gross/histology จริงจากสไลด์ (ฝังอยู่ในไฟล์แล้ว) + คำถาม + เฉลย
- **ตอบด้วยการพิมพ์** ไม่ใช่กดดูเฉลยตรง ๆ — ฝึกดึงความจำ (active recall) จริง ๆ
- **ตรวจสะกดแบบยืดหยุ่นด้วย Levenshtein distance**: ไม่สนตัวพิมพ์เล็ก/ใหญ่ ไม่สนช่องว่างเกิน
  พิมพ์ผิดเล็กน้อย (สลับตัวอักษร/พิมพ์ตกหล่นไม่กี่ตัว) ยังนับว่าถูก — พร้อม**ไฮไลต์ตำแหน่งที่สะกดผิด**
  เป็นตัวอักษรสีแดง (ผิด) และตำแหน่งที่ขาดหาย (สัญลักษณ์ ‸ สีส้ม)
- **รับคำตอบได้หลายแบบต่อการ์ด** (ชื่อเต็ม/ตัวย่อ/ชื่อพ้อง) เช่น
  "myocardial infarction" / "acute myocardial infarction" / "myocardial necrosis"
- **ปุ่ม override** "ตอบถูกแต่พิมพ์ผิด" — กดเองได้เมื่อมั่นใจว่าคำตอบถูกแนวคิด
  แต่ระบบตรวจสะกดเข้มเกินไป (เช่น ตอบด้วยคำพ้องที่ไม่ได้ใส่ไว้ในระบบ)
- **Spaced repetition แบบ SM-2** เก็บ ease factor, interval, จำนวนรอบ (repetitions) และวันครบกำหนด
  ต่อการ์ด ให้คะแนน 4 ระดับ (ลืม/ยาก/จำได้/ง่าย) หลังตรวจคำตอบทุกครั้ง
- **เพิ่ม/แก้/ลบการ์ดได้ในหน้าเว็บ** พร้อมอัปโหลดรูปจากเครื่อง (แปลงเป็น data URI อัตโนมัติ)
- **นำเข้า/ส่งออกเป็นไฟล์ JSON** เดียว รวมความคืบหน้า SM-2 ไว้ด้วย — ย้ายเครื่อง/สำรองข้อมูลได้
- **เก็บข้อมูลใน IndexedDB** ทั้งหมด ไม่มีการส่งข้อมูลออกจากเครื่อง
- **โหมดจำลองสอบ (Exam simulation)**: จับเวลา 60 วินาทีต่อข้อ หมดเวลาแล้วเด้งข้อถัดไปทันที
  ไม่มีการเฉลยระหว่างสอบ (เหมือนสอบ OSPE จริง) สรุปผลถูก/ผิดพร้อมเฉลยหลังทำครบทุกข้อ

ธีมเดียว: กระดาษชาร์ตคนไข้ / ป้าย slide สีฟ้าอมเขียวห้องแล็บ พื้นขาวสะอาด
เน้นให้ภาพ gross/histology เด่นและอ่านง่ายที่สุด รองรับทั้งธีมสว่าง/มืดของระบบ

## โครงสร้างไฟล์

ทุกอย่างอยู่ใน `index.html` ไฟล์เดียว (ประมาณ 6 MB ส่วนใหญ่คือรูปภาพที่ฝังไว้):

- CSS ทั้งหมดอยู่ใน `<style>`
- ข้อมูลการ์ดตั้งต้น 63 ใบ (คำถาม/คำตอบ/คำอธิบาย/รูปภาพเป็น base64) อยู่ใน
  `<script id="seed-data" type="application/json">` — ใช้ตอนเริ่มต้นครั้งแรกเท่านั้น
  (ถ้าอยากได้กลับมาหลังลบทิ้ง กดปุ่ม "โหลดชุดคำถามตัวอย่าง" ที่หน้าหลัก)
- โค้ดแอปทั้งหมดอยู่ใน `<script>` ท้ายไฟล์ (IndexedDB wrapper, Levenshtein diff,
  SM-2, หน้าทบทวน/จัดการการ์ด/นำเข้าส่งออก/จำลองสอบ)

## หมายเหตุเรื่องข้อมูล

- ข้อมูลทั้งหมดอยู่ในเบราว์เซอร์เครื่องที่เปิดไฟล์นี้เท่านั้น — ล้างข้อมูลเบราว์เซอร์ (clear site data)
  หรือเปิดในโหมดส่วนตัว (incognito) แล้วปิดไปจะทำให้ความคืบหน้าหายไป **ควรส่งออกไฟล์สำรองเป็นระยะ**
- เปิดไฟล์นี้จากคนละเครื่อง/คนละเบราว์เซอร์ = คนละชุดข้อมูล (IndexedDB ผูกกับ origin ของเบราว์เซอร์นั้น ๆ)
  ใช้ฟังก์ชันนำเข้า/ส่งออกเพื่อย้ายข้อมูลข้ามเครื่องได้
- ผลจากโหมดจำลองสอบจะถูกป้อนเข้า SM-2 ด้วย (ตอบถูก = จำได้, ตอบผิด/หมดเวลาไม่ตอบ = ลืม)
  เพื่อให้คิวทบทวนสอดคล้องกับผลจริงที่ทำได้
