# OSPE Immune 2 — แฟลชการ์ดฝึก Lab OSPE

เว็บแฟลชการ์ดสำหรับซ้อม Lab OSPE ของ **Immune 2** แยกเป็น 2 เรื่องตามบรรยาย
ดูภาพหรือใบรายงานผลแล้ว **พิมพ์คำตอบเอง** ระบบตรวจตัวสะกดแบบยืดหยุ่น
และจัดคิวทบทวนแบบ SM-2 ให้อัตโนมัติ ทั้งหมดอยู่ใน `index.html` ไฟล์เดียว (ภาพฝังอยู่ในไฟล์)

| เรื่อง | ที่มา | การ์ด | สถานี (มีภาพ/ใบรายงานผล) |
|---|---|---|---|
| 1 · Lab infection | La-or Chompuk, M.D. ภาควิชาพยาธิวิทยา (83 สไลด์) | 176 | 153 |
| 2 · Infectious immunodiagnosis | Infectious Immunodiag 69 (ซิฟิลิส, HBV/HCV) | 117 | 72 |

**หมวดย่อย**

- เรื่องที่ 1: Bacterial 33 · Mycetoma & Splendore–Hoeppli 22 · Fungal 56 · Viral 33 · Parasitic 32
- เรื่องที่ 2: ซิฟิลิส ระยะโรคและรอยโรค 34 · ซิฟิลิส การตรวจและแปลผล 47 · ไวรัสตับอักเสบบี/ซี 36

## คุณสมบัติ

- **การ์ด 4 แบบ**
  - ภาพ gross/histo/รอยโรค ให้ตอบการวินิจฉัย เชื้อ หรือโครงสร้างที่ชี้ด้วยตัวอักษร A/B/C
  - **ใบรายงานผล** serology 26 ใบ ให้แปลผล เช่น RPR/TPHA, HBsAg/anti-HBc/anti-HBs, anti-HCV/HCV RNA
  - กราฟ serologic profile ของซิฟิลิส, HBV acute/chronic และ HCV
  - **การ์ดบรรยายลักษณะ** 38 ใบ ตรวจตามประเด็นสำคัญที่ต้องมี
- **ตรวจคำตอบแบบยืดหยุ่น**
  - ไม่สนตัวพิมพ์เล็ก/ใหญ่และเครื่องหมายวรรคตอน
  - ยอมให้สะกดผิดเล็กน้อยทีละคำ แล้วแสดงตำแหน่งที่สะกดผิด
  - คำที่สลับกันแล้วความหมายเปลี่ยนจะไม่นับว่าถูก เช่น reactive/nonreactive,
    treponemal/nontreponemal, IgM/IgG, HBsAg/HBeAg/anti-HBs, acute/chronic, septate/nonseptate
  - ตัวเลขต้องตรงทุกตัว
- **SM-2** ปุ่ม ลืม / ยาก / จำได้ / ง่าย
  - การ์ดที่กด "ลืม" จะวนกลับมาในรอบเดียวกัน
  - ระยะห่างตั้งแต่ 21 วันขึ้นไปนับว่าจำได้แม่น
- **จำลองสอบ**
  - เลือกได้ 10/20/40 สถานี หรือทั้งหมด
  - จับเวลา 30/60/90 วินาทีต่อสถานี
  - เลือกเฉพาะสถานีที่มีภาพหรือใบรายงานผลได้
  - สรุปคะแนนพร้อมทบทวนข้อที่ผิด
- **จัดการการ์ด** ค้นหา เพิ่ม แก้ไข หรือซ่อนการ์ดได้ และคืนค่าการ์ดตั้งต้นได้ทุกเมื่อ
- **สำรองข้อมูล** เป็นไฟล์ JSON หรือเป็นข้อความ นำเข้าแล้วรวมกับของเดิมโดยเก็บรอบทบทวนล่าสุดไว้
- ธีมสว่าง/มืดตามระบบ และรองรับมือถือ

## ความคืบหน้าเก็บที่ไหน

- **เปิดผ่าน claude.ai (Artifact)**
  - เก็บในบัญชีของผู้ใช้แต่ละคนแยกกัน คนอื่นมองไม่เห็น เปิดจากเครื่องไหนก็ทบทวนต่อได้
  - ถ้าบันทึกขึ้นบัญชีไม่ได้ เช่นได้สิทธิ์แค่ดู จะเก็บไว้ในเบราว์เซอร์แทน และหน้าแรกจะบอกไว้
- **เปิดไฟล์ `index.html` โดยตรง** เก็บใน IndexedDB ของเบราว์เซอร์ (`ospe-immune2`)

## ภาพประกอบ

- ภาพทั้งหมด 98 ภาพ ตัดจาก PDF ของบรรยายทั้งสองเรื่อง
- ข้อความในสไลด์ถูกลบออกจาก PDF ก่อนเรนเดอร์ คำบรรยายและป้ายชื่อที่เป็นเฉลยจึงหายไป
  แต่ลูกศรยังอยู่
- ป้ายที่ฝังมากับภาพถูกระบายทับ (ไม่ได้ซ่อนด้วย CSS)
- จุดที่ต้องการถาม เช่น septum, scolex, เส้นกราฟแต่ละเส้น ใส่ตัวอักษร A/B/C กำกับแทน

## หมายเหตุเนื้อหา

- เอกสาร Immunodiag หน้า 9 มีบรรทัดที่เขียนว่า treponemal test "positive until cure"
  ซึ่งขัดกับตารางแปลผล หมายเหตุของ reverse algorithm และกราฟในบรรยายเดียวกัน
  (treponemal antibody มักเป็นบวกต่อไปหลังรักษาหาย) การ์ดยึดตามส่วนหลัง
  และเขียนหมายเหตุไว้ในการ์ด `des-tt-after-cure`
- การ์ดแต่ละใบมีช่อง `src` บอกหน้าสไลด์ที่มา ใช้เทียบกับบรรยายได้

## โครงสร้างไฟล์

```
index.html              แอปที่ build แล้ว (เปิดได้เลย ไม่ต้องใช้ไฟล์อื่น)
cards.json              เนื้อหาการ์ดทั้งหมดแบบไม่มีภาพ ไว้ตรวจทาน
src/
  build.py              รวมทุกอย่างเป็น index.html และ cards.json
  head.html             ธีมและสไตล์
  body.html             โครงหน้าเว็บ
  app.js                การตรวจคำตอบ, SM-2, จำลองสอบ, การ์ด, การบันทึกข้อมูล
  content/cards_lab.py  การ์ดเรื่องที่ 1
  content/cards_dx.py   การ์ดเรื่องที่ 2
  images/               ภาพ WebP ที่ลบป้ายเฉลยแล้ว
  test/                 ทดสอบการตรวจคำตอบ และทดสอบในเบราว์เซอร์ (Playwright)
```

## Build และทดสอบ

```bash
cd immune2-ospe/src
python3 build.py              # สร้าง ../index.html, ../cards.json และ out/artifact.html
node test/grading.test.js     # คำตอบที่ยอมรับต้องผ่าน คำตอบที่สับสนต้องไม่ผ่าน
node test/cross.test.js       # หาคู่การ์ดที่คำตอบของใบหนึ่งไปผ่านอีกใบ
node test/e2e.js              # เปิดหน้าเว็บจริง (ต้องมี Playwright)
```

`out/artifact.html` คือหน้าเดียวกันแบบไม่มีโครง `<html>` สำหรับเผยแพร่เป็น Artifact บน claude.ai
