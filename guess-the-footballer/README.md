# แข้งปริศนา — เกมทายนักเตะ

เกมทายชื่อนักเตะจากคำใบ้ 5 ข้อ เล่นในเบราว์เซอร์ได้เลย ไม่ต้องใช้เซิร์ฟเวอร์และไม่ต้อง build
ทุกอย่าง (หน้าเว็บ สไตล์ ข้อมูลนักเตะ และตัวเกม) อยู่ในไฟล์ `index.html` ไฟล์เดียว

## กติกา

- เกมละ 10 คน แต่ละคนมีคำใบ้ 5 ข้อ เรียงจากยากไปง่าย:
  เกร็ด → โปรไฟล์ (ตำแหน่ง สัญชาติ ปีเกิด) → เส้นทางค้าแข้ง → ผลงานเด่น → เสื้อแข่ง
- ยิ่งเปิดคำใบ้น้อย ลูกบอลยิ่งอยู่ไกลประตูและได้แต้มมาก
  (กลางสนาม 5 · ระยะไกล 4 · หัวกะโหลก 3 · จุดโทษ 2 · หน้าปากประตู 1)
- ทายผิดครั้งแรกโดนใบเหลือง ผิดครั้งที่สองเป็นใบแดง ไม่ได้แต้มจากคนนั้น
- พิมพ์ชื่อเป็นไทยหรืออังกฤษก็ได้ แล้วเลือกจากรายการที่ขึ้นมา
- เลือกชุดนักเตะได้ 4 ชุด: ทั้งหมด · ยุคนี้ · ตำนาน · พรีเมียร์ลีก
- สถิติดีที่สุดของแต่ละชุดเก็บไว้ในเบราว์เซอร์เครื่องนั้น (`localStorage`)

## เปิดเล่น

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ หรือเสิร์ฟผ่านเว็บเซิร์ฟเวอร์ธรรมดา:

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000/guess-the-footballer/
```

## เพิ่มหรือแก้นักเตะ

แก้ที่อาร์เรย์ `PLAYERS` ใน `index.html` หนึ่งคนคือหนึ่งออบเจ็กต์:

```js
{id:'salah', th:'โมฮาเหม็ด ซาลาห์', en:'Mohamed Salah', aka:['โม ซาลาห์'],  // aka = คำค้นเพิ่มเติม
 era:'now',            // 'now' หรือ 'legend'
 pl:1,                 // 1 ถ้าเคยเล่นพรีเมียร์ลีก
 pos:'ปีก', nat:'อียิปต์', born:1992,
 clubs:['บาเซิ่ล','เชลซี','โรม่า','ลิเวอร์พูล'],
 fact:'คำใบ้ข้อ 1 (ยากที่สุด)',
 feat:'คำใบ้ข้อ 4 (ผลงานเด่น)',
 kit:'liv', no:11, back:'M. SALAH'}   // kit ต้องมีใน KITS, back = ชื่อหลังเสื้อ ตัวพิมพ์ใหญ่
```

ห้ามใส่ชื่อของเจ้าตัวลงใน `fact` หรือ `feat` ชุดแข่งใหม่เพิ่มได้ที่ `KITS`
(ลาย `plain` `stripes` `check` `sleeves` `band`)

ข้อมูลนักเตะอัปเดตถึงฤดูกาล 2025/26 สีเสื้อเป็นภาพประกอบโดยประมาณ ไม่ใช่ชุดแข่งจริงทุกรายละเอียด
