# Pathogen Dx Recall — แฟลชการ์ดทายเชื้อจากอาการ

แฟลชการ์ดสำหรับฝึก**ทายชื่อเชื้อจากอาการและ keyword ที่ใช้วินิจฉัย** แยก 3 สำรับ
Viral · Bacteria · Parasite สรุปจากสไลด์บรรยาย *Viral diseases 69*,
*Bacterial disease 69*, *Parasitic infection* และโจทย์เก่า MED23–MED29 (หัวข้อ 5–7)

## เนื้อหา

| สำรับ | การ์ด | เชื้อ (ไม่ซ้ำ) | การ์ดที่มาจากโจทย์เก่า |
|---|---|---|---|
| Viral | 49 | 38 | 18 |
| Bacteria | 75 | 60 | 26 |
| Parasite | 50 | 45 | 17 |
| **รวม** | **174** | | ครอบคลุมโจทย์เก่า **65 ข้อ** |

- ด้านหน้า: อาการ + keyword สำคัญ (ตัวหนาที่ไฮไลต์ = คำที่ใช้วินิจฉัย)
- keyword ทุกคำเป็น **medical term ภาษาอังกฤษตามที่สไลด์และโจทย์ใช้** เช่น *barking cough*,
  *nocturnal perianal pruritus*, *rice-water stools* ภาษาไทยมีแค่คำเชื่อม และคำบริบทไทยในวงเล็บ
  เช่น *uncooked freshwater crabs* (ปูน้ำตก) ชื่อหัวข้อย่อยก็ใช้ศัพท์อังกฤษตามสไลด์
- ด้านหลัง: ชื่อเชื้อ (ชื่อวิทยาศาสตร์เป็นตัวเอียง) · โรค/กลุ่มเชื้อ · ข้อมูลที่มักออกสอบ ·
  เลขหน้าในไฟล์สไลด์ · ★ ปีและข้อของโจทย์เก่าที่ใช้เชื้อนี้เป็นคำตอบ
- ✎ = ข้อความที่ถูกไฮไลต์ไว้ในชีท Parasite
- คางทูม (Mumps) ไม่มีในสไลด์ แต่มีในโจทย์เก่า จึงใส่ไว้ด้วย; Syphilis มีแค่ชื่อในหัวข้อ STDs

## โหมดทบทวน

- **การ์ด** — อ่านอาการ นึกชื่อเชื้อ กดดูคำตอบ แล้วให้คะแนนตัวเอง (จำได้ / ยังไม่แม่น)
  จบรอบแล้วทวนซ้ำเฉพาะใบที่ยังไม่แม่นได้
- **5 ตัวเลือก** — แบบข้อสอบ A–E ตัวลวงสุ่มจากหัวข้อเดียวกันก่อน และไม่เอาเชื้อซ้ำกับคำตอบ
- **รายการ** — ดูทั้งหมดพร้อมค้นหา (เช่น `eschar`, `rice-water`, `ปูน้ำตก`, `MED27`) ใช้ทวนก่อนเข้าสอบ
- ตัวกรอง: หัวข้อย่อย · เฉพาะที่เคยออกสอบ · เฉพาะที่ยังไม่แม่น · สุ่มลำดับ
- ความคืบหน้าเก็บใน `localStorage` ของเบราว์เซอร์เครื่องนั้น

| ปุ่ม | การทำงาน |
|---|---|
| `Space` / `Enter` | ดูคำตอบ · กดซ้ำ = จำได้ |
| `1` / `2` | ยังไม่แม่น / จำได้ |
| `←` `→` | ย้อนกลับ / ข้าม |
| `A`–`E` | เลือกคำตอบในโหมด 5 ตัวเลือก |

## การใช้งาน

เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย หรือเสิร์ฟทั้งโฟลเดอร์:

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000/pathogen-dx/
```

## รวมเป็นไฟล์เดียว และไฟล์สำหรับ Anki

```bash
node pathogen-dx/build.js
```

สร้างไฟล์ใน `pathogen-dx/dist/`

- `pathogen-dx.html` — ไฟล์เดียวจบ ส่งต่อหรือเปิดแบบออฟไลน์ได้
- `pathogen-dx.embed.html` — ตัดแท็ก `<html>/<head>/<body>` ออก สำหรับโฮสต์ที่ห่อโครงเอกสารให้เอง
- `pathogen-dx-anki.txt` — นำเข้า Anki ได้ (File → Import) คั่นด้วย tab, เปิด HTML,
  แท็กตามสำรับ/หัวข้อ เช่น `PathogenDx::Bacteria::gi` และรหัสโจทย์เก่า เช่น `MED24-11`

## โครงสร้างไฟล์

```
index.html          โครงหน้าเว็บ
assets/cards.js     เนื้อหาการ์ดทั้งหมด (แก้การ์ดที่นี่ที่เดียว)
assets/app.js       โหมดการ์ด / 5 ตัวเลือก / รายการ และการบันทึกความคืบหน้า
assets/styles.css   สไตล์ทั้งหมด (ธีมสว่าง/มืดผ่าน CSS custom properties)
build.js            รวมเป็นไฟล์เดียว + ส่งออกไฟล์ Anki
```

## การเพิ่มหรือแก้ไขการ์ด

แก้ที่ `assets/cards.js` เท่านั้น แล้วรัน `node pathogen-dx/build.js`

```js
{
  id: 'b-scrub', g: 'zoo',                       // id ถาวร + รหัสหัวข้อย่อย
  clue: '<b>Forest ranger</b> … <b>eschar</b> …',   // ด้านหน้า (<b> = keyword ภาษาอังกฤษ)
  org: '<i>Orientia tsutsugamushi</i>',          // ด้านหลัง: ชื่อเชื้อ
  dz: '<b>Scrub typhus</b> (ไข้รากสาดใหญ่)',
  keys: ['Vector: chigger …', 'Dx: IFA'],
  exam: ['MED27-11'],                            // โจทย์เก่า (ถ้ามี)
  src: 'หน้า 68–70'                              // หน้าใน PDF สไลด์
}
```

`id` ของการ์ดเป็นข้อความคงที่ ความคืบหน้าผูกกับ `id` จึงแทรกการ์ดตรงไหนก็ได้
แต่ถ้าเปลี่ยน `id` ความคืบหน้าของการ์ดใบนั้นจะเริ่มใหม่
ใส่ `k` ให้การ์ดที่เป็นเชื้อเดียวกันแต่ชื่อเขียนต่างกัน เพื่อไม่ให้โผล่เป็นตัวลวงของกันเอง
และใส่ `mcq: false` ให้การ์ดสรุปที่ไม่เหมาะกับโหมด 5 ตัวเลือก

> เนื้อหาจัดทำเพื่อการทบทวนก่อนสอบเท่านั้น ไม่ใช้แทนตำราหรือแนวเวชปฏิบัติ
