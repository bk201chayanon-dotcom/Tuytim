# OSPE Flashcards — Respiratory Pathology

เว็บ flashcard สำหรับติวสอบ OSPE วิชาพยาธิวิทยา **ระบบหายใจ (Respiratory system)**
เป็นไฟล์ HTML ไฟล์เดียว เปิดออฟไลน์ได้ทันที ไม่ต้องติดตั้งอะไรเพิ่ม
เป็นคนละวิชากับ [`ospe-flashcards/`](../ospe-flashcards/) (CVS) — แยกข้อมูลกันคนละชุด
ความคืบหน้าของสองวิชาไม่ปนกัน

ที่มาเนื้อหา: สไลด์ **Lab Respiratory System 2** ภาควิชาพยาธิวิทยา
(61 การ์ด ครอบคลุมทางเดินหายใจส่วนบน กล่องเสียงและมะเร็งกล่องเสียง pulmonary edema,
DAD/ARDS, pneumonia, lung abscess, วัณโรค, การติดเชื้อรา, CMV, emphysema,
bronchiectasis, มะเร็งปอดทุกชนิด และ mesothelioma)

## วิธีใช้

เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ (Chrome/Edge/Firefox) ได้เลย ไม่ต้องเสิร์ฟผ่านเว็บเซิร์ฟเวอร์
ข้อมูลทั้งหมด (การ์ด รูปภาพ ความคืบหน้า) เก็บอยู่ใน **IndexedDB ของเบราว์เซอร์เครื่องนั้น**
เก็บสำรองด้วยการส่งออกเป็นไฟล์ JSON ในแท็บ "นำเข้า/ส่งออก" เป็นระยะ

## คุณสมบัติ

- **การ์ดแต่ละใบ**: รูป gross/histology จริงจากสไลด์ + คำถาม + เฉลย + **คำบรรยายพยาธิวิทยา**
  ที่อธิบายว่าทำไมถึงตอบอย่างนั้น และจุดที่ใช้แยกจากภาวะใกล้เคียง
- **ปิดคำตอบในภาพแล้ว**: ป้ายกำกับและป้ายชื่อสิ่งส่งตรวจที่พิมพ์ติดมากับรูปต้นฉบับถูกแถบดำทับ
  และ**ไม่แสดงชื่อหมวดเหนือรูป**ระหว่างตอบ (เฉลยชื่อหมวดในกล่องผลหลังตรวจคำตอบแล้ว)
- **ตอบด้วยการพิมพ์** ไม่ใช่กดดูเฉลย — ฝึกดึงความจำจริง ๆ
- **ตรวจสะกดแบบยืดหยุ่นด้วย Levenshtein distance** ไม่สนตัวพิมพ์เล็ก/ใหญ่ ไม่สนช่องว่างเกิน
  พิมพ์ผิดเล็กน้อยยังนับว่าถูก พร้อม**ไฮไลต์ตำแหน่งที่สะกดผิด**
- **รับคำตอบได้หลายแบบต่อการ์ด** (ชื่อเต็ม/ตัวย่อ/ชื่อพ้อง) เช่น
  "diffuse alveolar damage" / "DAD" / "ARDS"
- **ปุ่ม override** "ตอบถูกแต่พิมพ์ผิด" กดเองได้เมื่อมั่นใจว่าตอบถูกแนวคิด
- **Spaced repetition แบบ SM-2** เก็บ ease factor, interval, จำนวนรอบ และวันครบกำหนดต่อการ์ด
- **เพิ่ม/แก้/ลบการ์ดได้ในหน้าเว็บ** พร้อมอัปโหลดรูปเอง
- **นำเข้า/ส่งออกเป็นไฟล์ JSON** รวมความคืบหน้า SM-2
- **โหมดจำลองสอบ** จับเวลา 60 วินาทีต่อข้อ หมดเวลาเด้งข้อถัดไป ไม่เฉลยระหว่างสอบ

## หมายเหตุเรื่องข้อมูล

- ใช้ฐานข้อมูลชื่อ `ospe-respi-flashcards` แยกจากวิชา CVS (`ospe-cvs-flashcards`)
  เปิดสองวิชาพร้อมกันได้ ความคืบหน้าไม่ทับกัน
- ข้อมูลอยู่ในเบราว์เซอร์เครื่องที่เปิดไฟล์นี้เท่านั้น — ล้างข้อมูลเบราว์เซอร์แล้วความคืบหน้าจะหาย
  **ควรส่งออกไฟล์สำรองเป็นระยะ**
- รูปภาพมาจากสไลด์บรรยาย ส่วนไฟล์ภาพจับหน้าจอจากโปรแกรมดูสไลด์ดิจิทัลเป็นเคสชุดเดียวกัน
  แต่มีกรอบและป้ายกำกับเฉลยทับอยู่เต็มภาพ จึงใช้รูปจากสไลด์บรรยายซึ่งสะอาดกว่าเป็นหลัก
