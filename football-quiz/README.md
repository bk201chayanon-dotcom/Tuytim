# ชื่อนี้ใครเตะ — เกมใบ้ชื่อนักเตะวางบนหน้าผาก

เกมใบ้ชื่อสำหรับเล่นกันเป็นกลุ่ม ใช้กติกาเดียวกับ [`anime-quiz/`](../anime-quiz/)
แต่เนื้อหาเป็น **ชื่อนักเตะ** 275 ชื่อ จาก 3 หมวด
คนตอบวางโทรศัพท์บนหน้าผากโดยหันจอออกให้เพื่อน เพื่อนช่วยกันใบ้
ทายให้ได้มากที่สุดภายในเวลาที่กำหนด ทำงานทั้งหมดในเบราว์เซอร์ ไม่ต้องต่อเน็ต

## กติกา

1. คนตอบวางโทรศัพท์ไว้บนหน้าผาก หันจอออกให้เพื่อน ๆ เห็น ตัวเองห้ามชะโงกดู
2. เพื่อนที่เห็นจอช่วยกันใบ้เอง จอไม่บอกอะไรนอกจากชื่อ
   ห้ามพูดชื่อบนจอหรือส่วนหนึ่งของชื่อ
3. ตอบถูก เพื่อนกดปุ่ม **ถูกต้อง** · ใบ้ไม่ออกหรือคิดไม่ทัน กดปุ่ม **ข้าม**
4. เล่นรัวไปเรื่อย ๆ จนหมดเวลา **100 วินาที** จำนวนชื่อที่ตอบถูกคือคะแนน
5. เปลี่ยนคนทายแล้วเล่นต่อได้เลย ชื่อที่เคยขึ้นจอไปแล้วจะไม่กลับมาอีก

## หมวด

| หมวด | จำนวน | เนื้อหา |
|---|---|---|
| บอลโลก | 101 | ตำนานและดาวเด่นบนเวทีฟุตบอลโลก ตั้งแต่เปเล่ถึงเอ็มบัปเป้ |
| พรีเมียร์ลีก | 84 | ตำนานและดาวดังของลีกอังกฤษ |
| ลีกทั่วโลก | 90 | ลาลีกา กัลโช่ บุนเดสลีกา ลีกเอิง อเมริกาใต้ เอเชีย และไทยลีก |
| รวมทุกหมวด | 275 | สุ่มปนกันทั้งสามหมวด |

นักเตะที่ดังทั้งในบอลโลกและระดับสโมสรถูกจัดไว้หมวดเดียวเท่านั้น
เพื่อไม่ให้โหมดรวมทุกหมวดเจอชื่อเดียวกันสองครั้ง

## คุณสมบัติ

- **ไม่สุ่มซ้ำ ทั้งในรอบเดียวและข้ามรอบ** — เปลี่ยนคนทายแล้วเล่นรอบใหม่
  จะได้ชื่อใหม่ทั้งหมด ชื่อที่เคยขึ้นจอแล้ว ไม่ว่าจะตอบถูกหรือกดข้าม
  จะไม่กลับมาอีกจนกว่าจะเจอครบทุกชื่อในหมวดนั้น หน้าปกบอกว่าเหลือชื่อใหม่กี่ชื่อ
  และกด "ล้างประวัติ" เพื่อเริ่มนับใหม่ได้ทุกเมื่อ
- **แต่ละหมวดมีสีประจำตัว** — บอลโลกสีทอง พรีเมียร์ลีกสีชมพู ลีกทั่วโลกสีฟ้า
  ใช้กับแท็บชื่อหมวดและแถบเวลา ในโหมดรวมทุกหมวด สีจะเปลี่ยนตามหมวดของชื่อที่โผล่ขึ้นมา
- **จับเวลา 100 วินาที** เลือกเป็น 60 หรือ 150 วินาทีก็ได้ พร้อมเสียงติ๊กเตือน
  ช่วง 10 วินาทีสุดท้าย
- **สองปุ่มใหญ่เต็มความกว้าง** ปุ่มคงสีชอล์กกับหญ้าไว้เสมอ ไม่เปลี่ยนตามหมวด
  จะได้ไม่สับสนแม้ถือจ่อหน้าผาก
- **ไม่มีคำใบ้บนจอ** โดยตั้งใจ — เพื่อนที่ใบ้ต้องใช้ความรู้ตัวเอง
- **ปรับขนาดตัวอักษรอัตโนมัติ** ชื่อยาว ๆ อย่าง "เทรนต์ อเล็กซานเดอร์-อาร์โนลด์"
  จะย่อลงให้พอดีจอ และไม่ถูกตัดกลางคำ
- **สรุปผลท้ายเกม** บอกคะแนน ระดับ (จากม้านั่งสำรองถึงบัลลงดอร์)
  และรายการชื่อที่ผ่านไปพร้อมป้ายบอกว่ามาจากหมวดไหน
- **จำสถิติสูงสุด** แยกตามหมวดและช่วงเวลาไว้ใน `localStorage`
- **กันจอดับระหว่างเล่น** ด้วย Wake Lock API พร้อมเสียงและการสั่นตอบรับทุกครั้งที่กด
- **คีย์ลัด** — ลูกศรขวา / เว้นวรรค คือตอบถูก, ลูกศรซ้าย คือข้าม, `Esc` คือจบเกม

## หน้าตา

หน้าเว็บใช้ภาพจำของ **สนามหญ้าใต้ไฟสปอตไลต์** — หญ้าเขียวเข้มตัดลายเครื่องตัดหญ้า
เส้นสนามสีชอล์ก วงกลมกลางสนามอยู่หลังชื่อ และตาข่ายประตูที่สั่นทุกครั้งที่ตอบถูก
ตัวอักษรหัวเรื่องและชื่อนักเตะใช้ Bai Jamjuree ส่วนเนื้อความใช้ Noto Sans Thai
เป็นธีมมืดธีมเดียวโดยตั้งใจ ทาสีไว้ครบทุกค่า จึงอ่านได้เหมือนกันทุกที่

## การใช้งาน

เปิด `index.html` ด้วยเบราว์เซอร์ได้เลย หรือเสิร์ฟผ่านเว็บเซิร์ฟเวอร์ธรรมดา:

```bash
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000/football-quiz/
```

เล่นบนมือถือจะได้อารมณ์ที่สุด แนะนำให้**หมุนจอเป็นแนวนอน**และเปิดโหมดเต็มจอ

## รวมเป็นไฟล์เดียว

```bash
node football-quiz/build.js
```

จะได้ `football-quiz/dist/football-quiz.html` ที่ฝัง CSS และ JS ไว้ในไฟล์เดียว
เปิดออฟไลน์หรือส่งต่อให้เพื่อนได้ทันที และ `football-quiz.embed.html` สำหรับโฮสต์
ที่ห่อ `<html>` / `<head>` / `<body>` ให้เองอยู่แล้ว

## โครงสร้างไฟล์

```
football-quiz/
  index.html                 โครงหน้าและทั้งสี่ฉากของเกม
  assets/css/styles.css      ธีมสนามหญ้าใต้ไฟสปอตไลต์ ทาสีทุกค่าไว้ชัดเจน
  assets/js/questions.js     คลังชื่อนักเตะ — แก้เนื้อหาที่ไฟล์นี้ไฟล์เดียว
  assets/js/game.js          วงจรของเกม จับเวลา คะแนน เสียง และการเก็บค่า
  build.js                   รวมทุกอย่างเป็นไฟล์เดียวใน dist/
```

เกมนี้แยกไฟล์ออกจากเกมอื่นในรีโปอย่างสมบูรณ์ ไม่แชร์โค้ดกัน
ตามแบบเดียวกับโปรเจกต์อื่นที่แต่ละอันเปิดเดี่ยว ๆ ได้เอง แก้อันหนึ่งจึงไม่กระทบอีกอัน

## การเพิ่มหรือแก้ไขชื่อ

แก้ที่ `assets/js/questions.js` เท่านั้น แต่ละข้อคือข้อความชื่อล้วน ๆ

```js
{
  id: 'premier',
  name: 'พรีเมียร์ลีก',        // ชื่อบนแท็บระหว่างเล่น
  en: 'PREMIER LEAGUE',        // ชื่ออังกฤษบนไพ่เลือกหมวด
  hue: 'pl',                   // สีประจำหมวด ดูค่าที่ตั้งไว้ใน styles.css
  blurb: 'ตำนานและดาวดังของลีกอังกฤษ',
  items: [
    'อลัน เชียเรอร์',
    'เอริค คันโตน่า'
  ]
}
```

ชื่อที่ยาวเกินหนึ่งบรรทัดไม่ต้องกังวล ตัวเกมจะย่อขนาดให้เอง —
แต่ควรเว้นวรรคระหว่างคำตามปกติ เพราะเกมใช้ช่องว่างเป็นจุดขึ้นบรรทัดใหม่
และห้ามใส่ชื่อซ้ำข้ามหมวด เพราะโหมดรวมทุกหมวดจะเจอชื่อเดียวกันสองครั้ง

## หมายเหตุ

เป็นเกมที่ทำขึ้นเพื่อความบันเทิงเท่านั้น ชื่อนักเตะสะกดตามที่คนไทยเรียกกันทั่วไป
ไม่มีความเกี่ยวข้องกับสโมสร ลีก หรือองค์กรใด ๆ
